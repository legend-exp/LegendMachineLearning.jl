LegendMachineLearning.HaarFeatures — Type
HaarFeatures(; n_samples=256, normalize=true, bl_window=0.0u"µs"..25.0u"µs")

Feature extractor: baseline subtraction (mean over bl_window), repeated pairwise Haar averaging down to n_samples samples, and, if normalize, division of each waveform by the larger absolute value of its extrema. The number of Haar passes is derived from the input length, so one extractor handles presummed and full-resolution waveforms of the same detector.

LegendMachineLearning._detector_sample — Method
_detector_sample(data, filekeys, row, n_det, strata, waveform_column, rng)
    -> (; sample, stats, n_scan, n_matched)

n_det rows for the detector of row, drawn in two passes. The scalar scan of filekeys gives the candidate rows; rows flagged by an aux trigger named in strata.exclude leave the pool, and add_pool_columns places the rest within it. scan_rows picks strata.n_scan pool rows, triggered ones first; their waveforms are read back from each file by event number and summarized by waveform_stats. From these scan rows select_indices draws n_det by strata.rules, and the sample takes the waveforms already read.

stats holds, for the sample rows, the rule inputs the sample does not carry: the saturation counts, the pool columns and the waveform statistics. n_scan is the number of scan rows and n_matched the number of them each rule selects.

LegendMachineLearning.add_pool_columns — Method
add_pool_columns(pool) -> TypedTables.Table

pool (a table with filekey, baseline and daqenergy columns) with two columns that place each row within the pool:

  • baseline_dev: |baseline - m| in units of the median of these absolute deviations over the pool, where m is the median baseline of the pool rows of the same filekey. The FPGA baseline drifts from file to file, so each row is compared with its own file. When more than half the pool sits exactly on its file median the unit is zero, and the column holds NaN and Inf.
  • daqenergy_rank: empirical quantile of daqenergy among the pool rows with daqenergy > 0, in (0, 1]; 0 for the other rows.

LegendMachineLearning.build_sample — Method
build_sample(data, filekey, config; rng, chinfo, filekeys) -> (; sample, stats, n_scan, n_matched)

Sample for the period and category of filekey: config.n_max waveforms split equally over config.detectors, each drawn by _detector_sample from the raw files filekeys and read from config.waveform_column. A detector whose pool falls short of its share of config.n_max contributes all of it and @warns about the shortfall instead of silently returning fewer rows than the caller might expect.

config.strata holds the selection parameters:

  • aux_triggers maps flag names to the detector ids of the aux trigger channels, ts_window is the coincidence window in µs by which their triggers are matched to the detector's events (125 when absent), and exclude lists the flags whose events stay out of the pool;
  • n_scan is the number of pool rows per detector whose waveforms are read and summarized, rows with daqenergy > 0 first (see scan_rows; 200 000 when absent, at least the per-detector share of n_max);
  • bl_window and tail_window ([start, stop] in µs, required) are the windows of waveform_stats;
  • rules is a list of {name, select, fraction} with select a LEGEND Julia expression over the columns of the scan table (see rule_predicate), and uniform the expression of the rows the remainder is drawn from ("daqenergy > 0" when absent). See select_indices.

The scan table has the columns of scan_candidates and add_pool_columns and those of waveform_stats.

Returns the sample, the rule inputs of its rows (stats, one row per sample row), and per detector the number of scan rows (n_scan) and the number of them each rule selects (n_matched), both as PropDicts keyed by detector.

filekeys defaults to the raw files of every analysis run of the period, so rows may come from any run of it; filekey itself only names the period and the category. chinfo supplies the detector, channel and det_type columns used to look up each entry of config.detectors; it defaults to the full channel map of filekey. Pass any other table with those three columns to run without a channel map, e.g. a hand-built TypedTables.Table against raw files that predate or lack channel-map coverage.

LegendMachineLearning.classify_filekey — Method
classify_filekey(data, fk, model; detectors, aux_triggers, exclude, ts_window, n_max_per_detector,
    waveform_column, classes, rng) -> TypedTables.Table

Raw events of fk of each of detectors, classified by model: a table with the columns detector, eventnumber, timestamp, daqenergy, waveform, label, margin (the probability of the label) and probabilities (per event, the probability of each class of classes; see predict_probabilities).

aux_triggers (name => detector pairs or a dictionary of them), ts_window and the flag names in exclude select events as in build_sample: events within ts_window of a trigger of an excluded aux channel are left out. Of each detector at most n_max_per_detector events are kept, drawn uniformly with rng, in file order. The waveforms are read from the raw column waveform_column.

LegendMachineLearning.scan_affinity_propagation — Method
scan_affinity_propagation(X; damp, preference_quantile, target_n_clusters=100, maxiter=1000, tol=1e-6, metric=Cityblock(), rng=Random.default_rng())

Run affinity propagation on every (preference, damp) grid point and pick the converged one whose cluster count is closest to target_n_clusters, fewest iterations on ties. Grid points share one similarity matrix and run sequentially: each cell's working set is four n×n matrices, so cells cannot run concurrently without either racing on the shared matrix or multiplying that memory by the number of threads. The shared matrix's diagonal is overwritten with the grid point's preference before each call, so it never holds a specific preference once the scan returns.

LegendMachineLearning.scan_candidates — Method
scan_candidates(data, filekeys, det, aux_triggers; ts_window) -> TypedTables.Table

Row scalars of every raw event of det in filekeys: filekey, eventnumber, timestamp, daqenergy, baseline, and the DAQ's counts of samples saturated at the low and high end of the ADC range, t_sat_lo and t_sat_hi, plus one Bool column per entry of aux_triggers (name => DetectorId pairs or a dictionary of them), e.g. :pulser => DetectorId(:PULS01). A flag is true where that aux channel has a triggered event (daqenergy > 0) within ts_window of the row's timestamp, the same coincidence the hit tier uses to mark pulser events.

Matching by time rather than by row works in both categories: a cal file stores only the channels that fired, so an aux channel there holds its own triggers and its own row count, while a phy file writes every DAQ event to every channel.

LegendMachineLearning.scan_rows — Method
scan_rows(daqenergy, n, rng) -> Vector{Int}

Sorted indices of min(n, length(daqenergy)) rows: rows with daqenergy > 0 drawn uniformly first, then, if those run out, rows with daqenergy <= 0. In a phy pool almost every row is an untriggered read with daqenergy == 0, and a uniform draw would leave the waveform rules few triggered events to act on.

LegendMachineLearning.select_indices — Method
select_indices(cand, n; rules, uniform, rng) -> (idx, stratum)

Sorted row indices of the candidate table cand together with the name of the stratum each one was drawn by, length(idx) == min(n, length(cand)).

rules is a sequence of (name::Symbol, select, fraction) in which select(cand) gives one Bool per row of cand; a missing or NaN result counts as false. The rules are drawn in order, without replacement and each only from rows the earlier ones left, up to round(Int, fraction * n) rows each; a rule with fewer rows than its quota gives what it has and leaves the rest of its share to the later strata. :uniform then fills the rest of n from the rows for which uniform(cand) is true, and :top_up from any rows still left.

n at or above length(cand) returns every row, labeled by the first rule it matches, else :uniform or :top_up.

LegendMachineLearning.train_svm — Method
train_svm(X, y, svm_config; groups, rng) -> (machine, report)

Grid search over cost × gamma with stratified n_folds cross-validation on balanced accuracy, then a refit on all data with the best pair. The report holds the grid scores, a holdout confusion matrix (20 % stratified split), per-class and per-group accuracy. groups (e.g. detector types) must be index-aligned with y. class_accuracy[i] is missing, not 0, when classes[i] has no rows in the holdout split.

LegendMachineLearning.waveform_stats — Method
waveform_stats(wvfs::ArrayOfRDWaveforms; bl_window, tail_window,
               trigger_threshold=5, trigger_mintot=2.0u"µs", tx_mintot=32.0u"ns") -> TypedTables.Table

One row of summary statistics per waveform, computed from the trace as recorded (no pole-zero correction):

  • blmean, blsigma, blslope, bl_slope_sigma: mean, standard deviation, fitted slope and standard deviation about the fitted line over bl_window, as the DSP's blmean, blsigma, blslope and bl_slope_sigma;
  • tailmean, tailsigma, tailslope: the same over tail_window of the baseline-subtracted trace, and tail_tau = -tailmean / tailslope in µs, the decay time of an exponential with that mean and slope; a flat or rising tail gives a non-finite or negative value;
  • wf_max, wf_min: extrema of the baseline-subtracted trace, amplitude = wf_max;
  • t10, t50, t90: first crossings of 10, 50 and 90 % of wf_max that stay above for at least tx_mintot, NaN when there is none; risetime = t90 - t10;
  • n_triggers: in-trace trigger multiplicity, counted as LegendDSP.get_triggers counts in-trace pile-up on the trace after a 2 µs rise, 1 µs flat-top trapezoidal filter: crossings of trigger_threshold times the sigma of the filtered trace over bl_window (measured from the start of the filtered trace) that last at least trigger_mintot.

The waveforms are processed in blocks, so the baseline-subtracted and filtered copies never exist for the whole array at once.
